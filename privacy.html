Privacy Policy

MIDAS · last updated 1 October 2026

MIDAS is a private tool run by Ryan (“the operator”). It prepares short educational videos and posts them to the operator’s own TikTok account. It is not offered to the public, has no sign-up, and has no users other than the operator. This policy explains what information the tool touches and why.

What the tool accesses on TikTok

When the operator signs in with TikTok (Login Kit) and approves the permissions, the tool receives:

  • the account’s basic profile information (an account identifier, display name and avatar), through the user.info.basic permission; and
  • the ability to publish videos to that account, through the video.publish permission (Content Posting API).

The tool does not read the account’s messages, followers, following list, comments or other people’s videos, and it does not collect information about any other TikTok user.

How the information is used

Only to sign the operator in and to publish the operator’s own, original videos to the operator’s own account, and to show the operator whether a post succeeded.

Where it is kept, and who sees it

The sign-in tokens TikTok issues are stored in a file on a private computer controlled by the operator, with file permissions that only the operator’s own user account can read. They are not published, sold, shared with anyone, or used for advertising, profiling or analytics. The tool uses no third-party trackers.

This website

These pages are static. They set no cookies, run no analytics and collect no personal information about visitors.

How long it is kept, and deleting it

Tokens are kept while the operator uses the tool. The operator can revoke the tool’s access at any time in TikTok (Settings → Security & permissions → Manage app permissions) and can delete the token file from the computer, which removes the tool’s ability to act on the account. Videos already posted stay on TikTok until the operator removes them there.

Children

The tool is not directed at children and does not knowingly collect information from anyone under 13 (or the minimum age in their country).

Your rights

The only person whose information the tool processes is the operator. If you believe it holds information about you, or you have any question about this policy, contact the operator at ryanreidpersonal@gmail.com. The operator is based in the United Kingdom and handles personal information in line with UK data protection law.

Changes

If this policy changes, the new version will be posted on this page with a new date.
